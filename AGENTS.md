# AGENTS.md

Инструкции для AI-агентов, работающих в этом репозитории. Для описания архитектуры проекта, команд сборки и CI/CD см. [CLAUDE.md](./CLAUDE.md).

## Качество кода

- **Без комментариев в коде.** Пиши самодокументирующийся код: понятные имена вместо пояснений.
- **Качество важнее количества.** Не разводи лишние абстракции, не пиши код "про запас" под гипотетическое будущее.
- **При выборе между костылём и переписыванием — выбирай переписывание.** Если исправление бага/добавление фичи упирается в развилку "починить быстро костылём" vs "разобраться и переписать как следует, пусть даже долго" — выбирай второе. Костыль сейчас почти всегда дороже в будущем.

## UI-конвенции

- **Уведомления только через `showCustomNotification(context, 'текст')`.** Никогда не используй `SnackBar` — в проекте единый кастомный компонент уведомлений.
- **Кнопки с переключаемой перечёркнутой/неперечёркнутой иконкой** (вспышка, микрофон, звук, уведомления) **должны анимироваться Lottie-иконкой**, а не мгновенно подменять один `Icon` на другой:
  1. Добавь спеку в `SLASH_SPECS` в `tool/make_morph_icons.py` (используй `fill=1.0`, если кнопка рисует `Icon(..., fill: 1)`).
  2. Прогони `python3 tool/make_morph_icons.py` — ассеты в `assets/lottie/` руками не редактируются, только через генератор.
  3. Выводи иконку через `LottieSlashIcon`.

## Тесты и данные

- **Никогда не оставляй реальные данные в тестовых файлах** — ни содержимое реальных сообщений, ни реальные ID, захваченные из запросов. Используй синтетические фикстуры.

## Сборка

- **Никогда не запускай сборку APK/AAB сам** (`flutter build apk`, `flutter build appbundle`, gradle assemble-таски) — это долго, и сборку всегда запускает пользователь. Для проверки достаточно `flutter analyze` (см. точную команду с исключёнными директориями в CLAUDE.md).

## Git

- **Никогда не делай commit, пока пользователь явно не попросит.** Это касается любых изменений, даже тривиальных (например, правки `.gitignore`) — оставляй их в рабочем дереве или в stash, не коммить по своей инициативе.
