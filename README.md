## Нативные уведомления
Версия для AppStore поддерживает нативные уведомления и звонки iOS за счёт *Push Proxy* – сервер от лица ПК клиента
получает уведомления/события от MAX по GSM и отправляет их по APNS. Для работы требуется в настройках уведомлений в 
Komet push server включить свой аккаунт и подтвердить авторизацию. Сервис поддерживает рассылку на несколько устройст
и рассылку на устройства с мультиаккаунтом.

**Вы не обязаны использовать!!**

Push Proxy не является рекомендованым способом получения уведомлений в Komet из-за рисков безопасности. Команда
Komet не несёт ответсвенности за Push Proxy и рекомендует использовать WEB-push.
