# Сопоставление с Komet, версия 0.2.6.0

«Есть код» ниже означает реализацию и сборку, а не подтверждённую работу
с настоящим аккаунтом. Авторизованные сценарии требуют проверки на W10M.

| Раздел оригинала | Состояние порта 0.2.6 |
| --- | --- |
| Основная сессия | Есть TLS StreamSocket, MessagePack, LZ4 block/frame, Zstd, тайм-ауты и ping; ping без блокировки UI, без ложного закрытия при отсутствии ответа на ping; обрыв восстанавливается автоматически; начальный обмен проверен на ПК |
| Вход по коду | Профиль совместимости, device ID, callsSeed, mode и fingerprint LOGIN; настоящий RESEND. Получение кода подтверждено пользователем в 0.2.0.0. Ошибка `[internal]` при следующем этапе потребовала поправок 0.2.0.1; вход пока не подтверждён |
| QR и 2FA при входе | Есть запрос/показ/опрос QR и ввод пароля; проверка аккаунтом требуется |
| Регистрация | Есть подтверждение имени через AUTH_CONFIRM, без выбора аватара в процессе регистрации |
| Несколько аккаунтов | Есть отдельные токены PasswordVault, переключение и добавление; локальный кэш хранит последний активный аккаунт |
| Чаты | Есть список, пагинация, поиск по загруженному списку и глобальный поиск; имена диалогов подгружаются через CONTACT_INFO; в строках и шапке показываются аватарки, в переписке — статус присутствия и переход в профиль по шапке; автообновление чатов и истории работает тихо, без блокировки интерфейса |
| История | Есть загрузка, предыдущие сообщения и локальный шифрованный кэш; нет полноценной базы/миграций оригинала |
| Текст | Есть отправка, ответ, пересылка, копирование, редактирование, удаление у себя/всех, закрепление |
| Прочтение | Есть ручная отметка и настройка запрета; нет полного автоматического поведения оригинала |
| Реакции | Есть отправка, отмена и счётчики |
| Отложенные сообщения | Есть планирование текста; отдельный список, редактирование/отмена отложенного пока не перенесены |
| Группы и каналы | Есть создание с выбором контактов, вступление по ссылке, сведения и первая страница участников; нет полного администрирования |
| Контакты | Есть список, поиск по номеру, начало диалога, добавление, блокировка/разблокировка |
| Профиль | Есть имя/фамилия и загрузка фотографии |
| Устройства | Есть просмотр сессий и завершение остальных |
| Настройки | Есть локальные ghost/anti-read, настройки превью push аккаунта и очистка кэша; нет полного набора приватности, 2FA-настроек, оформления и производительности |
| Файлы | Скрепка слева от поля ввода с меню файлов, фото, камеры, аудио и стикеров; есть потоковая отправка и сохранение; нет очереди параллельных загрузок, возобновления и подробного прогресса |
| Фотографии | Есть выбор/системная камера, multipart-загрузка, просмотр, сохранение и аватар профиля; фотографии и стикеры отображаются прямо в переписке с кэшем ссылок; нет редактора и галереи оригинала |
| Видео/аудио | Есть Play/Pause для аудио, голосовых и видео прямо в сообщении; Ogg/Opus декодируется встроенными libopus/opusfile/ogg в WAV, прочие форматы воспроизводит MediaElement; поддержка видео зависит от кодеков ОС |
| Голосовые и видеокружки | Запись, Opus/Ogg, waveform и отдельные загрузчики не перенесены |
| Отправка видео | Можно отправить как файл; специализированная чанковая загрузка VIDEO не перенесена |
| Стикеры | Есть список паков, выбор и отправка; нет анимации Lottie, полного избранного и редактора |
| Опросы | Есть создание, одиночный/множественный выбор и отправка голоса; расширенное управление опросом не перенесено |
| Звонки | Есть история; медиадвижка и UI разговора нет. Проверенный готовый ARM32 mrwebrtc_uwp 2.0.2 требует 17763+ |
| Уведомления | Есть foreground toast и in-process фоновые ApplicationTrigger/SocketActivityTrigger, TLS socket broker с keepalive и резервной TimeTrigger-задачей; WNS/WebPush не перенесены. Реальные фоновые пробуждения на W10M ещё не проверены |
| Истории | Не перенесены |
| Комментарии/каналы | Базовая переписка работает через общие методы; отдельные треды и комментарии не перенесены |
| Папки, избранное, архив | Избранное с chatId=0 доступно; папки и архив не перенесены |
| Мини-приложения, боты, команды | Нативный мост/WebView и интерактивные кнопки не перенесены |
| Digital ID и NFC | Не перенесены |
| Облачное хранилище MAX | Не перенесено |
| Дополнительное шифрование Komet | Не перенесено; зашифрованный локальный кэш — отдельный механизм Windows |
| Прокси/VPN bypass | Не перенесены |
| Локализация | В порте русский интерфейс, нет всей системы переводов оригинала |
| Темы/анимации/обои | Есть системный UWP-дизайн; дополнительные темы, обои, Lottie, шейдеры и кастомизация оригинала не перенесены |

В ходе проверки не использовались реальные номера, OTP, пользовательские токены
и содержимое переписок. Устройство не подключено к локальному Device Portal,
поэтому автоматическая проверка авторизованных сценариев на телефоне недоступна.

В 0.2.4 проверены ARM32, синтетическое декодирование mono/stereo Ogg Opus,
loopback-сессия без ответов на ping и с тайм-аутом одного запроса, протокол/TLS.
Визуальный запуск макета на ПК заблокирован политикой sideload (0x80073CFF).
